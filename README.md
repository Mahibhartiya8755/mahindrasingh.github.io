## Run Project Locally

Clone the repository:

```
git clone https://github.com/mahi-8755652540/My-portfolio.git
```

Go to the project folder:

```
cd My-portfolio
```

Install dependencies:

```
npm install
```

Run development server:

```
npm run dev
```
